# pel-pdf-spreadsheet
The macOS Number spreadsheet used to create the [PEL PDF files](https://pierre-rouleau.github.io/pel/)
including the [PEL PDF Index](https://pierre-rouleau.github.io/pel/pel-table-based-documentation1/-index.pdf).

⚠️  **Note**  I do not update this repo very often.
If you want me to update it to get the latest source I use
to create the PEL PDF files, please request it by creating an
issue inside this repository.
